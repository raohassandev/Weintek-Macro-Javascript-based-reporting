# Native EasyBuilder Pro object-by-object commissioning guide

**Evidence:** DOC/OFFLINE, not an EBPro-compiled functional screen. **Source-of-truth screenshot** is the approved 1672×941 teal/green image (NOT PR #46). Build one cMT-FHDX-220 window 210 at 1920×1080. 44-inch display legibility and model version need actual site acceptance.

1. **Picture background:** Choose genuine `background-only-1920x1080.png` from approved source package and set as static Picture at (0,0). Preserve original labels/units/panel borders/icon geometry. *Never* place original preview with green status dots as live background. Current GitHub binary publication pending.
2. **Client-private meter select:** Combo Box/Function Key for 1..61; proposed `PLW-100`; proposed private index register `PLW-9200` offset=(meterID−1)×128, NEVER global `LW-9200`. Validate Weintek per-client private index and session isolation on installed firmware before use. Selecting meter cannot start/stop native Data Sampling.
3. **Voltage Numeric Display:** L1N/L2N/L3N + average, L1L2/L2L3/L3L1; phase/V engineering units are static in backdrop; native numeric fields overlay blank slots. Capability and quality guard: missing/not supported -> N/A (not 0).
4. **Current Numeric + Bar Graph:** L1,L2,L3 and neutral current if meter provides. Native current bars need scaled instrument rating, never static green bar fills. Max/avg only with identified formula and valid inputs.
5. **Phase & Total P/Q/S/PF:** For each of 4 rows use phase A/B/C + TOTAL displays. P measured (kW), Q measured (kvar), S measured (kVA), PF measured where possible. Derived apparent power/PF must be labeled and fail N/A on bad inputs or harmonics ambiguity.
6. **Frequency/Demand/Phase Loading:** Numeric Display for Hz, kW current/peak demand and load factor; phase loading% needs rated current/voltage and genuine per-phase measurement, else N/A. No device health/IP/protocol fields in operator page.
7. **Power Quality:** Native Numeric Displays for V-THD, I-THD, voltage/current imbalance and harmonic where supported. Optional analyzer fields must not default zero. Quality and out-of-range data overrides all decorative states.
8. **Computed insights:** 12 calculated values, each with explicit source tags/quality, formula, nominal thresholds supplied by engineering/site contract. Good/stale/offline/unknown Word Lamps and status labels; no green by default or invented fault interpretation. A bad phase or zero denominator -> N/A.
9. **24h Trend:** Native Trend Display or History Data Display with persistent per-meter Data Sampling. History is independent of current volatile LW index; missing periods show gaps and coverage. Binding to private index does NOT automatically retarget native logger's historical source.
10. **7-day energy comparison:** Native Bar/Trend object driven by proven on-device result, counter delta reset-aware or kW×time integration with gap policy. NEVER sum sampled kW directly to claim kWh.
11. **History Snapshot filters:** Combo Box meter/metric/interval, Date/Time from/to, bounded query request, observed record coverage. Operator **never sees SQL statement, database schema, username, meter IP or development registers**. Query result rows timestamp, parameter, unit, min/max/average (only if honestly computed), provenance.
12. **SQL Query object:** Official FHDX software matrix lists SQL Query; **Advanced arbitrary SQL on Local USB SQLite remains unverified**. Follow `planning/2-meter-fhdx220/SQL_QUERY_TEST_PLAN.md`. Do not mark Local SQL PASS from desktop SQLite simulation. If Advanced unavailable, test native History Data Display as separate scope, not equivalent arbitrary reporter.
13. **Export CSV:** Native Backup/Function Key action only after real USB1 media writable/progress/latest-record and separate verified backup. FHDX-220 has ONE USB2 port and NO SD; no PDF generator proof. Disable action until true device validation.
14. **Alarms & Events:** Native EBPro Event/Alarm Display, configured data source and severity/ack UAC, not HTML table or a static recent-alarm picture. Persistent incident event log unaffected by window selection.
15. **UAC/safety:** Read-only reporting page; no Modbus writes/control via viewer without separate commissioning authorisation. Test two simultaneous viewers' meter selections and history filters. Site SLD remains a different per-site page.

**Exact object placement:** `tags/original_ebpro_object_schedule.csv` (108 rows) contains original image X/Y and scaled 1920×1080 X/Y/W/H with required object type/source and per-row evidence status. These are design candidate objects until an actual EasyBuilder project is imported and compiled.
